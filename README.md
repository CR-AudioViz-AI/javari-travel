# JavariTravel - Worldwide Travel Deals

**Part of the CR AudioViz AI Ecosystem**

A nationwide/worldwide travel deals platform that shares its core infrastructure with [Orlando Trip Deal](https://orlandotripdeal.com).

## 🌍 Features

- **Global Hotel Deals** - Best prices from major booking sites
- **Flight Comparisons** - Real-time flight price tracking
- **Vacation Packages** - Bundled deals for maximum savings
- **AI Price Predictions** - ML-powered best time to book recommendations
- **Deal Alerts** - Get notified when prices drop

This platform uses the **Henderson Standard** architecture:

- ✅ Centralized payments (Stripe + PayPal)
- ✅ Centralized email alerts
- ✅ Centralized AI predictions
- ✅ Shared component library

## 📦 Tech Stack

- Next.js 14 (TypeScript)
- Supabase (PostgreSQL)
- Tailwind CSS
- Central services from craudiovizai.com
